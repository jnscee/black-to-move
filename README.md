# Black to Move

팬텀하이브 저택에서 시엘을 안은 세바스찬을 조작하는 한국어 비공식 흑집사 팬게임입니다.

**[브라우저에서 게임 시작](https://jnscee.github.io/black-to-move/)**

PC에서는 방향키나 WASD로, 모바일에서는 전투판을 드래그해 이동합니다. 시작 지점 오른쪽에 있는 청록색 포크에 다가가면 **파편 +1**이 뜨고 은식기 쌍투가 열립니다. 현관홀과 서재 회랑에서 동료를 영입하고 연회장의 보스를 격파하세요.

## 프로젝트 파일

- `index.html`은 그림을 내장한 게임 실행본입니다. 내려받아 오프라인으로도 플레이할 수 있습니다.
- `Black_to_Move_Source.zip`에는 수정 가능한 HTML·CSS·JavaScript, 원본 WebP, 빌드 스크립트와 브라우저 테스트가 들어 있습니다. 압축 안의 README에서 빌드와 테스트 방법을 확인할 수 있습니다.
